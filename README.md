# Latent Space Jam

Static project page. Host on GitHub Pages like any other static site.

1. Create a GitHub repository and upload these files to the root (keep `index.html` at the top level).
2. In the repo: **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: `main` / `/ (root)`
3. The site will be at `https://<user>.github.io/<repo>/`

Paper / Video / Code buttons are placeholders (`href="#"`). Set those links in `index.html` when you have URLs.
